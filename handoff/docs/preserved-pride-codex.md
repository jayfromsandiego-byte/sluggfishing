## The codes
1. Show the work, never state the identity (YETI shows a grizzly failing, never a slogan)
2. Borrow a trusted unglamorous real-world system (Flighty = airport boards // ours = the landing fish count, checked obsessively since 1935, 976-TUNA since 1985)
3. The user's real history rendered as a trophy (Strava/Flighty Passport // ours = gyotaku, 1839 proof-of-catch prints — as a MECHANIC, never wallpaper)
4. Instrument-grade trust is the gate (mono numerals, named sources, timestamps — "the wardens use it too")
5. Insider depth outsiders wouldn't get (bank numbers as map labels, verified slang only)
6. Anti-technical-look restraint (Howler: "nobody's going to go 'oh my god that's a fishing shirt'" // Flighty's goal: "boringly obvious")
7. Real named people, real stakes (Tommy, the shop, real boats — never stock models)
8. Social ritual over solo-hero performance (Duck Camp vs Orvis, the generational code)
9. NEVER monetize the trust mechanic (Surfline cam paywall rage, Garmin badge-points, onX offline lockouts)
10. Scale corny-fies — stay understated as we grow (Salty Crew's post-acquisition "Salt Life or Salty Crew?" mockery)
